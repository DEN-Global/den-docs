# Sharper light theme

Updated shared light tokens and transport/shipment copies: mint-white backgrounds, deeper forest text, stronger field outlines and solid green primary actions. Light headings use weight 600. Background canvas supports up to 2× device scale and stronger light opacity. Dark palette is unchanged.

Contrast checks: primary text 11.68:1, secondary text 6.52:1, white action text 7.98:1, input boundaries at least 3:1 against white. Browser inspected the empty sign-in form, mobile widths (345 CSS pixels after viewport scaling) without horizontal overflow, and theme switching. Screenshot: light-signin.png.
